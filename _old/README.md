# Archived compatibility implementation

This directory preserves the former C# and MAUI implementation as design
evidence. Every archived file keeps its original repository-relative path
below `_old/` so references and relationships remain easy to follow.

The archive is not part of the active StateUI product. It is not built, tested,
packaged, launched, or kept in sync with the Swift core and native hosts. New
work belongs in the active Swift packages; archived files change only when an
explicit historical correction is requested.
