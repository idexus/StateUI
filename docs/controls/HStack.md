# HStack

Stacks its children left to right, each as wide as it asks to be.

```swift
HStack {
    Image("home.png")
    Text("Home")
}
.spacing(8)
```

Layer: `native`. Every base host presents it with its native toolkit.

Inherits: [AutomationElement](tiers/AutomationElement.md) · [VisualElement](tiers/VisualElement.md) · [View](tiers/View.md) · [Layout](tiers/Layout.md) · [Stack](tiers/Stack.md) · [PaddingElement](tiers/PaddingElement.md) · [BorderElement](tiers/BorderElement.md) · [KeyboardElement](tiers/KeyboardElement.md)
